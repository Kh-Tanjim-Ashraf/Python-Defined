# Initialize a Python Project using UV

Navigate into the sepacific folder & initialize a Python project with standard directory structure & configuration files.

> uv init

The project folder includes the following files:

1. `.git`: Initializes the hidden `.git` folder.
2. `.gitignore`: Initializes the `.gitignore` file which is used by git to ignore specified files in this project folder.
3. `.python-version`: Defines the Python version which will be used by `UV`.
4. `main.py`: This file provides a boilerplate Python function by `UV`.
5. `pyproject.toml`: This file holds a detail information about this Python project & dependencies used by `UV`.
6. `README.md`: A rich text document file for this project.

Execute/run this python project using the following command:

> uv run <python-file>.py
